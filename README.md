
# Grupo13 Analytics

**Grupo13 Analytics** es una empresa joven dedicada a la ciberseguridad, formada por tres profesionales especializados en auditoría, análisis de vulnerabilidades y protección digital.

Este repositorio contiene la versión web del proyecto final, desarrollado como simulación real de una consultora de seguridad informática. Está desarrollado con HTML, CSS (TailwindCSS) y JavaScript.

---

## 🌐 Sitio web

Puedes visitar la web online desde GitHub Pages:  
👉 [https://mariomf91.github.io/grupo-13-analytics](https://mariomf91.github.io/grupo-13-analytics)

---

## 📄 Secciones del sitio

- **Inicio** – Presentación de la empresa
- **Servicios** – Descripción de auditorías y áreas de trabajo
- **Quiénes somos** – Información sobre los fundadores
- **Contacto** – Datos de contacto y formulario
- **Auditorías realizadas** – Informes en PDF, videos y evidencias de auditorías (en proceso)
